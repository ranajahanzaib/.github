# Security policy

Please do not report security vulnerabilities through public GitHub issues or pull requests.

When a repository has private vulnerability reporting enabled, use its **Security** tab to submit a private report. Otherwise, contact [work@withrana.com](mailto:work@withrana.com) with a description of the issue, its potential impact, and steps to reproduce it. Avoid including credentials or other sensitive data in an initial report.

This account-wide guidance is a fallback. A repository's own security policy may provide more specific reporting instructions.
