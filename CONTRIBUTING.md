# Contributing

Thanks for taking the time to contribute. Each repository may have its own setup instructions, conventions, and checks, so start by reading that project's README and contribution guidance.

## Before opening an issue or pull request

- Search existing issues and pull requests to avoid duplicates.
- For bugs, include the affected version or commit, steps to reproduce, expected behavior, and actual behavior. Remove secrets and personal data from logs and examples.
- For larger changes, open an issue first to discuss the proposed approach.

## Pull requests

- Keep each pull request focused and explain the problem it solves.
- Follow the repository's existing style and include or update tests and documentation when relevant.
- Run the checks documented by the project and report which ones you ran.
- Describe any breaking changes and link related issues.
