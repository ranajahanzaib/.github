# GitHub account configuration

This repository contains the profile page and shared GitHub community files for [Rana Jahanzaib](https://github.com/ranajahanzaib).

## Profile page

The public profile landing page is maintained in [`profile/README.md`](profile/README.md). GitHub displays that file on the account profile. This README describes the repository and its shared defaults.

## Shared community files

GitHub can use community health files in this repository as defaults for other repositories owned by this account when those repositories do not provide their own versions.

- [`CONTRIBUTING.md`](CONTRIBUTING.md) — contribution and pull request guidance
- [`SECURITY.md`](SECURITY.md) — private vulnerability reporting guidance
- [`.github/ISSUE_TEMPLATE/`](.github/ISSUE_TEMPLATE/) — issue forms for bugs and feature ideas
- [`.github/PULL_REQUEST_TEMPLATE.md`](.github/PULL_REQUEST_TEMPLATE.md) — pull request checklist

Project-specific instructions take precedence. These defaults should stay broadly applicable across the account's repositories.

## Maintenance

Keep the profile page focused on the public introduction and project showcase. Update shared guidance here when the account's contribution or security process changes.
